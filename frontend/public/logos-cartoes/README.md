# Logotipos de cartões

Recursos exportados em 2026-09-01 do arquivo comunitário
[Brazilian Banks Logos](https://www.figma.com/design/saB9XZOboU8BaFKpdA7EgP/Brazilian-Banks-Logos--Community-?node-id=0-1),
fornecido como referência pelo proprietário deste projeto.

O componente `LogoCartao` usa o nome do cartão para escolher o recurso e mantém um ícone genérico
quando não há correspondência.
